# WLC.IA

Estúdio de desenvolvimento com IA conectado ao GitHub.

- **Chat** — conversa livre com a IA.
- **Planejar** — a IA monta um plano e pede aprovação.
- **Criar** — a IA grava o código no repositório.
- **WLC.IA (Chat Cognitivo)** — onde você ensina conhecimento novo aos motores.

Documentação detalhada será reorganizada.
